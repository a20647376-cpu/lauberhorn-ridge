# Lauberhorn Ridge

A single-page hiking trail guide for Lauberhorn Ridge above Interlaken, Switzerland.

**Status:** design demo (static page, sample content)
**Author:** Sassui Irfan, Islamabad, Pakistan

## What the page shows

- Hero section for Lauberhorn Ridge
- A simple 3-day plan
- Trail information
- Ready-made packages
- A "Plan this trip with us" section

## Run it

Open `index.html` in any browser. It is one self-contained file and needs no setup.
